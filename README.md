# Weather Clock App

A Node.js app that displays the current time, date, and weather.

## Structure
```
weather-clock-app/
├── package.json
├── README.md
├── src/
│   ├── index.js     Server
│   ├── config.js    Cities, languages, and weather colors
│   ├── weather.js   Weather fetching
│   └── page.js      HTML page
└── public/
    ├── style.css    Styling
    └── app.js       Clock and scene (in the browser)
```
